Playbook

How to use the console

  1. 01

    Paste

    Drop a player link, an index.m3u8 URL, a cookie string or a full manifest. The example button loads a wrapper link you can try.

  2. 02

    Inspect

    Keep Scan the manifest tree on to follow variant playlists. Press Ctrl + Enter instead of the button if you prefer.

  3. 03

    Read

    Every source gets a card: host, token fields, start and expiry time, live countdown, signed variants and the requests the scanner made.

Pass one

Link anatomy

Host, path segments and decoded query fields, with timestamps, hashes and signatures flagged.

Pass two

Manifest body

Reads the playlist itself, so hdnts=exp=…, st=… and key URIs show up even without a token in the link.

Pass three

Variant walk

Follows up to three levels and lists each resolution, bitrate and signed segment link.

Pass four

Token decode

JWT payloads, AWS presign fields and lifetime values become a start, an expiry and a countdown.

Disclaimer

Use it on sources you are allowed to inspect

Token Inspector is a read-only diagnostic tool. It fetches manifests you provide, never stores them, and redacts signatures and credentials in every report. It does not bypass DRM, membership or paywalls, and it is not a downloader. You are responsible for the links you submit.

Availability is best-effort: CDNs may rate-limit, geo-block or reject scanner requests, and a failed fetch is reported as a failed request rather than a guess.
