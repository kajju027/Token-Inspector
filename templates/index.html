How it scans

Four passes, one readable report

  1. 01 Link anatomy

    Splits the URL into host, path segments and decoded query fields, then flags timestamps, hashes and signatures.

  2. 02 Manifest body

    Reads the playlist source itself, so hdnts=exp=…, st=… and encrypted key URIs are found even when the URL has no token.

  3. 03 Variant walk

    Follows up to three levels of variant playlists and lists every resolution, bitrate and signed segment link.

  4. 04 Token decode

    Decodes JWT payloads, AWS presign fields and lifetime values into a start time, an expiry time and a live countdown.
